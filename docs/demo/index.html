ecommerce-order-pipeline

订单 ETL 可视化演示 Order Pipeline Demo

读取 CSV，隔离坏行，用整数分计算金额，在一个事务里写入数据库，再用 SQL 对账。重跑不会产生重复数据。 Small batch ETL in Python: quarantine with an audit trail, money in integer cents, one-transaction load, SQL reconciliation, idempotent reruns.

事务失败与重跑

  • 同一文件重跑：接收 26，写入 0，未变化 26；数据库状态完全相同。
  • 第二批写入失败：失败前事务内已有 2 次写入，数据库报错后整批回滚；订单 26 → 26，批次 1 → 1，问题记录 7 → 7，状态完全相同。
  • 修正后重跑：接收 27，写入 2，未变化 25；订单 27，paid 销售额 72.00 元。
