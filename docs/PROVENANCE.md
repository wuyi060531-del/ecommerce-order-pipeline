# 来源与归因

这个仓库是从一个私人的学习与工程混合仓库中，按白名单提取出来的。只带走了生产代码、SQL、必要的测试和工程工具，没有带走原来的 Git 历史、个人作答、课程材料、学习进度或内部记录。逐文件的源 SHA、目标 SHA 和适配标记见 [SOURCE_MAP.json](SOURCE_MAP.json)，这些源版本标识只用于追溯，不代表本仓库继承了原提交历史。

## 谁写了什么

数据管道、数据库层、审计、测试、性能工具，以及这次拆分，主要由 Codex 在我的授权下完成。

原学习过程中，有一部分由我填写、经过提示修改的转换表达式，曾被原工程复用。公开版没有复制课堂脚手架或作答文件，而是按这些已有的业务约定，重新写了一个最小实现放在 `src/order_pipeline/transforms.py`：8 个带类型标注的转换函数，负责副本、筛行、日期、Decimal 金额和城市汇总。`quality`、`pipeline` 改为包内导入，SQLite / MySQL 的存储层和 SQL 保持原样。

这个项目不是我独立设计和编写的。Git 作者字段不能说明这一点，我对代码的掌握程度，要靠自己复现和讲解来证明。

## 与原工程的差异

- 保留了原工程的 7 个测试文件。`test_learning_isolation.py` 和 `test_challenge_workflow.py` 是教学工具的自检，共 39 项，没有复制过来，也没有用 skip 凑通过。原来的 164 项中剩余 125 项作为回归基础，最终数量以[实际运行结果](VALIDATION.md)为准（当前 145 项）。
- 样本相关的测试只改了新的 synthetic ID、商品汇总和 6600 分这个预期值，数量、输入保护、异常、事务、幂等、SQL 和失败恢复的断言都保留。
- Dockerfile 和构建上下文去掉了课程文件，对应的静态断言改为不允许出现任何 Day 文件。
- 原来的 CSV 没有复制。新样本和生成方法见[数据说明](../data/README.md)。

本仓库的 Git 历史独立于私人学习仓库。
